## Title

Login for Your FastMCP Server From Your Own User Table

## Description (one or two sentences)

A tutorial on making a FastAPI app the OAuth 2.1 authorization server for its own MCP
server with GotAuth, an open-source auth library, so Claude and other MCP clients sign
users in from the app's database. It covers resource-bound tokens, scope step-up and
revocation.
