MCP servers built with FastMCP or the official MCP SDK can accept GotAuth access tokens: `fastmcp_auth` and `mcp_sdk_auth` in `gotauth.integrations.mcp` verify them in the same process or against a remote issuer, serve the RFC 9728 metadata, answer 401 and 403 with the challenges MCP clients need to sign in and step up, and give tools the user, agent and scopes through `current_access()`.
