Add `gotauth check` (also `python -m gotauth.checkup`), a standard-library-only static scanner that finds 13 kinds of risky hand-written auth code (passlib and python-jose imports, hard-coded JWT secrets, unverified JWT decoding, timing-unsafe comparisons, disabled TLS checks, weak password hashing, insecure cookies and CORS) and prints a 0-100 score as text, JSON or SARIF 2.1.0.
