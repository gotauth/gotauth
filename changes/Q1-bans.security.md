A banned user's OAuth tokens and API keys are refused everywhere, not only on GotAuth's own endpoints. Before, `verify_access_token` (used by MCP servers in the same process) and introspection still accepted the user's access tokens, the refresh grant still issued new ones, and `verify_api_key` still accepted the user's keys. The new `auth.check_principal(ctx, principal)` runs every plugin's principal checks for code that accepts a credential outside the request pipeline.
