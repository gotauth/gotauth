Add the crypto kit `gotauth.crypto.crypto_kit(secret, *, password_algorithm="scrypt")`: scrypt password hashing (argon2id with the `argon2` extra, verify-only bcrypt for imported passlib hashes), an unknown-user check that takes as long as a wrong password, HMAC signing and AES-256-GCM encryption bound to a purpose with secret rotation, HKDF key derivation, TOTP, numeric one-time codes, PKCE and monotonic ULIDs, plus language-neutral spec vectors in `spec/`.
